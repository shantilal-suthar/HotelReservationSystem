 Hotel Reservation System 

A simple console based Java application built to manage hotel room searches, bookings, payments, and real-time room availability.

This project was developed as a core Object-Oriented Programming (OOP) practice project using basic Java concepts like Encapsulation, Classes, Objects, and ArrayList collections.

Features :

1.Search Available Rooms: Filter available rooms by room type (Standard, Deluxe, Suite) and desired booking dates.

2.Room Reservation: Reserve a room by providing customer details (Name, Phone, Email) and selecting a preferred payment method.

3.Real-time Availability Management: When a room is booked, its availability status updates automatically across the system.

4.Booking Confirmation Receipts: Generates a formatted text receipt with a unique Reservation ID, payment status, and stay dates upon successful booking.

5.View Room & Reservation Records: View live room availability or check all existing reservation receipts anytime from the menu.


Execution Steps :

- Clone or Download the Repository:
Save the code into a single file named HotelReservationSystem.java.

- Open Terminal / Command Prompt:
Navigate to the directory where HotelReservationSystem.java is saved.

    cd path/to/your/folder


- Compile the Java File:

   javac HotelReservationSystem.java


- Run the Application:

  java HotelReservationSystem
